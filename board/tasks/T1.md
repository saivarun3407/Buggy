# T1 — The agent builds its own checks when no tool fits

Epic: **E14** · Lane: **C** · Depends on: nothing

## What

A check is described as data (steps, extractions, a verdict with a control) and run by Buggy through the gateway, so scope, approval and the ledger still apply. A hit is re-proven by running the check again.

## Done when

It runs on the real stack against the local practice apps, the tests and `make ci-lint` pass, and the card says what was measured and what was not.
