# T3 — Scope shown as four lists: in scope, out of scope, do, don't

Epic: **E14** · Lane: **E** · Depends on: none

## What

Every command that shows a scope (`buggy hunt`, `scope show`, `scope import`, `scope set`) prints the same four lists and nothing else. The lists are built by rule from the stored scope and, for a bounty program, its program record.

## Done when

The four lists print from a real `buggy hunt` command, a switch (port scan, account creation, practice target) moves its line between do and don't, and the tests and `make ci-lint` pass.
