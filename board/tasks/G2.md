# G2 — Test one bug class after another and say what happened to each

Epic: **E14** · Lane: **C** · Depends on: nothing

Read `board/AGENT_RULES.md` and `board/CONTRACTS.md` first.

## What

The test phase runs class by class in a fixed order. The result and the report carry a table: for every class, tested or not, how many checks ran, findings, and why a class was not tested.

## Done when

It runs on the real stack against the local practice apps, the tests and `make ci-lint` pass, and the board card says what was measured and what was not.
