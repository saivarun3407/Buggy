# T4 — Recon covers the web app and its APIs, not only the network

Epic: **E14** · Lane: **A** · Depends on: none

## What

Two built-in recon stages, read-only, rate-limited and inside the scope:

- `web`: robots.txt, sitemaps and security.txt; missing security headers, session cookie flags and version banners; sign-in, sign-up, reset, MFA, OAuth, account and admin pages by kind.
- `api`: API roots and the versions served; OAuth / OpenID discovery; one GET with no login per concrete API endpoint (status, credentials asked for, CORS, rate-limit headers, field names).

Their records become leads (an open endpoint with an object id or sensitive fields, a bearer-token endpoint, CORS with credentials, several API versions, each sign-in page kind) and report sections.

## Done when

It runs on the real stack against the local practice apps, the tests and `make ci-lint` pass, and the card says what was measured.
