# B2 — Wildcard DNS filter

Epic: **E02** · Lane: **B** · Depends on: B1

Read `board/AGENT_RULES.md` and `board/CONTRACTS.md` first.

## Why (who does this well, and what Buggy lacks)

RedAmon probes each root with random names and drops subdomains that resolve only because of a wildcard record. Without this, one wildcard zone floods the store with fake hosts and every later stage wastes requests on them.

## Idea

Detect wildcard zones deterministically and keep only names that are real.

## Architecture

New module `pipeline/wildcard.py`:
- `probe_names(root, n=3, rng=secrets) -> list[str]`: `n` random 16-char labels under `root`.
- `detect(root, resolve) -> WildcardInfo(root, is_wildcard, addresses: frozenset[str])` where `resolve(names) -> dict[name, set[str]]` is the pipeline's existing DNS path (dnsx runner) — all `n` random names resolving to the same non-empty address set means wildcard.
- `filter_names(names, info, resolved) -> (kept, dropped)`: under a wildcard zone, keep a name only if its address set differs from the wildcard set, or it is the root itself, or it was explicitly listed in scope / seed URLs.
Integrate in `pipeline.py::_stage_dns`: one detection per enumeration root (cache result in the stage cache keyed by root), apply the filter before records are stored, log every dropped name through the existing scope-drop logger with reason `wildcard_dns` (direction `output`). Record a `dns_record` with `attrs.wildcard=true` for the root. Detection probes go through the same resolver options and rate limit as the stage.

## Out of scope

Changing enumeration tools. Anything outside the DNS stage.

## Tests that must exist and pass

- wildcard zone: 50 enumerated names all resolve to the wildcard address, 2 resolve elsewhere -> only those 2 (and the root) are kept; 48 drops are logged with reason `wildcard_dns`.
- non-wildcard zone (random names do not resolve): nothing dropped (negative control).
- partial wildcard (random names resolve to rotating addresses, i.e. sets differ between probes): treated as not-wildcard and nothing is dropped; test documents this choice.
- an explicitly scoped host under a wildcard zone is kept even if it shares the wildcard address.
- deterministic with an injected rng.
