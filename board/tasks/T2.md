# T2 — The agent can look things up on the public internet

Epic: **E14** · Lane: **F** · Depends on: nothing

## What

Web search plus a page fetcher that refuses the target's hosts, internal addresses and URLs that carry target data. The target stays reachable only through the gateway.

## Done when

It runs on the real stack against the local practice apps, the tests and `make ci-lint` pass, and the card says what was measured and what was not.
