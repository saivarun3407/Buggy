`hackerone_scope.csv` uses the exact header row of the scope CSV a HackerOne
program page serves (checked against a live download on 2026-11-19: asset
types such as `URL` / `OTHER`, `eligible_for_submission` as `true` / `false`,
`max_severity` in lower case). The rows are synthetic and use reserved
`.example` names and documentation address ranges; no real program's scope is
stored in this repository.
